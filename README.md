## Projeto em destaque: Compra360

Sistema web em desenvolvimento para apoiar a gestão e análise de compras no varejo supermercadista.

O projeto nasceu de necessidades identificadas na minha rotina profissional e reúne:

- Importação e tratamento de dados de arquivos CSV.
- Consulta de produtos e fornecedores.
- Indicadores e gráficos de compras.
- Consulta de entradas de mercadorias.
- Configuração de alertas.
- Autenticação com JWT.

Atuo na definição dos requisitos, estruturação do banco de dados, desenvolvimento do backend e frontend e validação das funcionalidades.

O Compra360 já foi implantado no Google Cloud, utilizando Cloud Run e Cloud SQL durante o período de avaliação da plataforma. Atualmente, o sistema é executado e desenvolvido em ambiente local.
